BACKEND -
📁 Kis file ka kya kaam hai? -
    | File                               | Kaam                                                     |
| ---------------------------------- | -------------------------------------------------------- |
| `server.js`                        | Main backend server + routes connect karta hai           |
| `.env`                             | Gemini key, email credentials, port                      |
| `.gitignore`                       | `.env` aur `node_modules` ko GitHub se protect karta hai |
| `config/mail.js`                   | Nodemailer/Gmail configuration                           |
| `routes/contactRoutes.js`          | Contact form ka API route                                |
| `routes/chatRoutes.js`             | AI chat ka API route                                     |
| `controllers/contactController.js` | Contact form ka actual email logic                       |
| `controllers/chatController.js`    | Gemini AI ko message bhejta hai                          |
| `utils/emailTemplate.js`           | Contact email ka HTML template                           |
| `middleware/errorHandler.js`       | Backend errors handle karta hai                          |
